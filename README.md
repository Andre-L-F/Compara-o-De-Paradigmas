# Sistema de Estoque em  C#

Implementação do projeto da N1 no paradigma Orientado a Objetos, usando C#.

## Requisitos

- .NET SDK 10.0 ou superior.
- VS Code com C# Dev Kit

## como que faz pra rodar esse trem 

1. Abre o terminal na pasta do projeto.
2. Execute:

```bash
dotnet restore
dotnet run
```
## Como explicar a orientação a objetos

- Quando você cria um produto o mesmo se torna um objeto com seus devidos dados/atributos onde ele pode "passear" pelo sistema com toos estes atributos intactos ja que eles estão ENCAPSULADOS,ou seja, ninguem pode mexer neles vindo de outra classe somente sentro da classe produto isso você pode mostrar para o professor bem na classe produto onde os atributos estão como privados    (bem parecido na verdade igual ao java ) com isso esses dados podem ser consultados por outras claasses que chamam o objeto produto assim como está no menu.
